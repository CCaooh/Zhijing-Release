# 织境

织境是一款面向 Windows 的截图、标注、长截图、OCR、翻译和屏幕录制工具。

本仓库仅用于发布正式二进制版本和自动更新清单，不包含织境的闭源源代码。

## 主要功能

- 多显示器与高 DPI 区域截图
- 矢量标注、文字、马赛克、模糊和荧光笔
- 自动及手动竖向、横向长截图
- 钉图、截图历史和二次编辑
- 本地及网络 OCR、翻译
- MP4/GIF 区域和窗口录制
- 录屏期间实时标注

## 下载与使用

1. 打开右侧的 Releases，下载 `zhijing-1.0.0-windows-x64.zip`。
2. 解压到一个可写目录。
3. 运行文件夹内的 `织境.exe`。

织境 1.0.0 当前未使用 Authenticode 商业代码签名。Windows 第一次运行时可能显示未知发布者提示，请仅从本仓库的正式 Release 下载，并核对 SHA-256。

## 完整性校验

`zhijing-1.0.0-windows-x64.zip`

```text
3E10347B17B4327AAE56026E71D93A2769E7140BCEDBFEB07F17B5643FC1BF31
```

程序自动更新还会验证 ECDSA 签名清单、文件大小和 SHA-256；校验失败时不会安装更新。

## 系统要求

- Windows 10 或 Windows 11，64 位
- 部分网络 OCR/翻译服务需要用户自行配置服务商账号

## 开源依赖

织境自身保持闭源。正式 Release 同时提供 Qt/FFmpeg 对应源码归档及第三方许可材料，用于履行相关开源许可证义务；该归档不包含织境自有源代码。
